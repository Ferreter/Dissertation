# Saved model artifacts

The model directories are populated when the relevant notebooks run with `SAVE_MODEL_ARTIFACTS = True`.

```text
models/
├── classical/
│   ├── rq1_direction.joblib
│   ├── rq2_magnitude.joblib
│   ├── rq3_large_move.joblib
│   └── manifest.json
└── lstm/
    ├── rq1_direction.keras
    ├── rq1_direction_scaler.joblib
    ├── rq2_magnitude.keras
    ├── rq2_magnitude_scaler.joblib
    ├── rq3_large_move.keras
    ├── rq3_large_move_scaler.joblib
    └── manifest.json
```

The classical artifacts are fitted on the original Train + Validation development sample. The exploratory LSTM artifacts are selected and refitted only on the permitted extended development sample. Existing Test rows and the fresh post-17-Jul-2026 holdout are excluded from fitting.

Each manifest records the source notebook, research question, target, feature order, training dates and row count, excluded splits, model parameters, classification threshold where applicable, package versions, file hashes and reload-verification status.

These binary files are intentionally not generated by the repository refactor. Run the documented notebooks to create them in the local environment used for the dissertation.
